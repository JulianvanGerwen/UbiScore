# UbiScore
Code associated with the manuscript "Mapping the functional importance of site-specific ubiquitination across the human proteome" (doi.org/10.1101/2025.10.08.681129)

# Guide to files
The majority of the data processing and analysis is carried out by sequential .Rmd files in the main directory. The directory scripts/ provides supporting scripts. Additionally, several analyses are carried out by dedicated directories within scripts/, namely conservation/, hotspot_scripts/, and CPTAC/
